# ChatScope 0.1 — 微信聊天提取与分析（Windows 预览版）

面向普通用户的本地桌面工具。没有固定账号、盘符或聊天对象；连接由用户选择的账号后，只读生成数据库快照，再选择联系人或群聊进行提取、分析和导出。

## 运行

下载便携 ZIP 后完整解压，双击 `ChatScope.exe`。必须保留旁边的 `_internal` 文件夹。无需 Python，无需联网。当前包为 Windows x64，尚未进行代码签名；当前仅在开发机器实测，不是已完成广泛兼容测试的正式发行版。

1. 在电脑微信登录需要分析的账号。
2. 打开工具，选择账号并点击「连接并读取会话」。未自动发现时，用「选择数据目录」选择 `xwechat_files`、账号文件夹或 `db_storage`。
3. 左侧搜索联系人或群聊，选择目标。日期可留空；结束日期包含当天。关键词搜索正文，发言人按名称或 ID 包含匹配。
4. 点击「提取并分析」。初次提取会校验全部普通聊天分库，需要一定时间与临时磁盘空间；同次连接重复筛选复用快照。新消息需要断开后重新连接。
5. 查看聊天分页、词云、词频、每日消息趋势、24 小时分布、成员排行、情感分布及情感趋势。
6. 导出当前筛选结果为 JSON/CSV/TXT，或导出包含 PNG 图表、词频 CSV、统计 JSON 的本地 HTML 报告。

「体验演示」使用随包生成的虚构内容，不会读取真实聊天。

## 兼容范围和边界

- **已验证：微信 Windows 4.1.15.50、64 位 Windows 环境。** 读取适配参考 wechatauto-replica 的 WCDB 配置结构。
- 其他微信 4.x 版本只进行运行时校验，尚未逐版本实测；3.x 暂不支持。更新后读取失败会明确报错，不会把失败伪装为空聊天或自动切换其他账号。
- 范围是**本机存在的记录**，不补全未同步到电脑的手机历史，不恢复删除数据。
- 当前主要针对普通私聊、群聊消息。公众号独立 `biz_message` 分库、朋友圈、语音转写、媒体文件提取不在本版范围。媒体消息保留类型/文本元数据，不包含原始图片、音视频等文件。
- 日期使用本机时区。界面分页每页 200 条，导出覆盖当前筛选的全部结果。
- 中文词频使用 jieba，忽略单字、纯数字和标点；停用词可在界面追加，修改后再次提取分析。
- 情感使用 SnowNLP 通用中文模型，最多按时间顺序均匀抽取 2,000 条中文文本。每条最多前 1,500 字；积极 >0.65，消极 <0.35，其余中性。未抽中及非中文文本显示为「未评估」。报告记录样本量。该模型对口语、反讽和专业领域可能误判，不能用来测量真实情绪。
- 未解码正文会显示占位符，并在统计中单独报告，不计入词频和情感。无法识别的发送者保留数字标识。群成员排行使用账号 ID 后缀区分同名成员。

## 数据处理

程序运行不请求网络、不上传聊天。只读打开微信原始文件，不注入、不发送、不修改聊天。密钥只保存在进程内存，不保存到配置或日志。读取权限需与微信匹配；程序不会自动提权。

工作副本保存在系统临时目录下独立的 `chatscope-...` 文件夹。正常断开或关闭时删除；强制结束进程/断电可能留下副本，可在退出所有 ChatScope 实例后自行删除。导出的报告和聊天记录由用户选择位置保存，不会随临时副本清理。副本与导出文件都是明文。

源数据库与 WAL 在稳定复制后再解密；验证页 HMAC、WAL 校验和、事务提交边界及 SQLite quick_check。读取期间检测到源文件变化会重试，持续变化则报错。快照是各数据库分别取得的，聊天会话列表与消息不是跨库原子事务快照。

CSV 为避免电子表格执行公式，会对以 `= + - @` 起始的字符串加前导单引号；JSON 保留原始文本。

## 源码与构建

需要 Windows x64、Python 3.11 x64。运行 `build.ps1`，或创建虚拟环境、安装 requirements.txt 后运行 `python app.py`。单元测试：`python -m unittest discover -s tests -v`。

模块：`storage.py` 账号发现/快照/认证解密，`wcdb_keys.py` 版本相关参数读取，`reader.py` 联系人及消息解析，`analysis_engine.py` 离线统计，`charts.py` 图表，`exports.py` 导出，`app.py` 桌面界面。

真实账号测试数据、密钥、数据库和私人内容不包含在源码或软件包中。第三方说明见 THIRD_PARTY.md。

## 下一步适配建议

正式公开发行前，还需在不同 Windows 版本、微信版本、账号目录、权限设置与大数据量场景进行兼容测试，并补充签名、安装/卸载与升级机制。新微信版本优先修改独立读取适配模块，再通过数据库完整性和实际消息测试确认。
